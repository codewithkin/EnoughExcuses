### Tier 5: Live Activity (Dynamic Island + Lock Screen)

| Feature | Files | Commits |
|---|---|---|
| **FocusTimerActivity** (Live Activity) | `activities/FocusTimerActivity.tsx` — banner, compact leading/trailing, minimal, expanded layouts | 1 |
| **Live Activity lifecycle** | `lib/live-activity.ts` — `syncLiveActivity()` (start-or-update, keyed on task id so pause/resume never recreates the activity) + `stopLiveActivity()` | 1 |
| Wired into session lifecycle | `focus.tsx` — new effect alongside the notification/media-control ones, same 10s tick pattern | 1 |
| **FocusTimerLockScreen** (Lock Screen circular accessory) | `widgets/FocusTimerLockScreen.tsx` — `accessoryCircular` family, separate from the Live Activity itself (a standalone always-available complication) | 1 |
| Config plugin registration | `app.json` — added `FocusTimerLockScreen` to the `expo-widgets` plugin's `widgets` array (Live Activities need no app.json entry — `expo-widgets` auto-bundles any `createLiveActivity()` call) | 1 |
| Widget sync wiring | `lib/widget-sync.tsx` — `FocusTimerLockScreen.updateSnapshot()` added to `updateIOSWidgets()` | 1 |

Note: Live Activity / Dynamic Island is an Apple-only API — there's no Android equivalent. Android's live-timer surface is already covered by the Tier 2 lock screen notification + media controls, which shipped earlier.
